# Gastonsin — Car Dealership & Rentals

Next.js storefront for Gastonsin Car Dealership & Rentals: vehicle imports from
China, the USA and Dubai into Ghana, ready stock from the Nzema warehouse, and a
nationwide rental fleet.

## Development

```bash
npm install
npm run dev
```

The site runs at http://localhost:3000.

## Brand

The logo lives in `components/elements/Logo.tsx` — a geometric "G" whose open
counter and centre spoke also read as a steering wheel. Use `<Logo />` for the
lockup, `<LogoLink />` when it should link home, and `<LogoMark />` for the mark
on its own. Favicons are generated from the same shape in `app/icon.svg`.

## Branches

`gastonsin-catalogue-redesign` holds an alternative build of this site — an
8-page structure with a typed 39-model catalogue, filtered browsing and a booking
flow. Not in use; kept for reference.
